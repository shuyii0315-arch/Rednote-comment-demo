# 评论区互动 Demo

小红书 RPDC 体验设计笔试 · 主题 1「互动」的可交互原型。

在线体验：https://shuyii0315-arch.github.io/Rednote-comment-demo/

## 制作工具与过程

- 工具：Claude（编码与调试）、Figma（设计稿）、GitHub Pages（托管）。纯前端 HTML / JS，无后端。
- 过程：
  1. 先在 Figma 完成高保真稿和交互规则。
  2. 让 Claude 读取 Figma 稿，逐屏还原成可点击的页面。
  3. 再逐个补交互：长按选表情、半屏弹层、表情飘起、通知直达等。
  4. 每次改动后在电脑和手机上逐步点测，发现不对就让 Claude 改，再测。
- 分工：功能取舍、交互规则、表情的风格和数量、动效节奏由我决定和验收；AI 负责把这些实现成代码，并帮我检查各步骤有没有出错或错位。
